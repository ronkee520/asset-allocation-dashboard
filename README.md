面向资产配置分析师的跨资产研究看板，覆盖全球权益、债券、汇率、商品、AI产业链、资金流、宏观事件与相对配置评分。

## 在线访问

[打开全球资产配置研究终端](https://ronkee520.github.io/asset-allocation-dashboard/)

公开页面由 GitHub Actions 每 4 小时尝试更新。访问者直接打开固定链接即可使用，无需在本地运行脚本，也不会接触数据源密钥。

4. 20日/60日跨资产相关性与轮动矩阵：共同交易日对齐、Pearson与Spearman、置信区间、显著性与多窗口样本
5. 全球市场行情与趋势比较

## 资产配置评分

评分用于判断未来 1 至 3 个月的风险调整后战术配置吸引力。20日趋势、60日趋势、宏观适配、资金流或仓位、相对全球股票强弱和波动率约束分别转换为历史或同类位置，再按公开权重合成。价格因子使用最多约 5 年滚动观测，历史不足的因子按中性处理并降低数据质量：

`展示分 = 60 + 0.30 × 综合因子值`

全球股票、债券、商品、黄金和美元属于一级资产；AI、港股和A股属于权益内部方向，避免重复计算权益风险。市场风险偏好使用权益、信用、波动率、周期、美元压力和资金广度独立计算，不是八项资产分数的平均值。

用户也可以主动填写八项持仓比例，页面在浏览器中先按共同日期对齐各资产收益，再估算组合年化波动、最大回撤、下行波动率、95% 条件风险价值、集中度和风险贡献。该输入不会上传，也不会影响其他访问者。

价格子模型使用扩展窗口校准：每个信号阈值只使用当时以前的数据，20 日前瞻区间互不重叠，并与同一标的的无条件前瞻基准比较。页面中的“数据质量”只表示覆盖、来源状态和样本长度，不是统计置信水平。

## 周期与相关性模型

普林格时钟分别以债券、股票和商品的多只代表性ETF构建组合趋势，采用 `35% × 20日收益 + 65% × 60日收益`，再与六阶段方向模板计算双曲正切相似度。绝对趋势小于 0.5% 记为中性；最佳与第二候选相差不足 5 个百分点时，页面明确标记“阶段边界”，并报告近 20 个交易日的阶段稳定率。FRED 宏观数据只作交叉验证，不强行覆盖价格信号。

相关性矩阵先按日期取两项资产的共同收盘观测，再计算简单日收益率，避免不同市场节假日造成错位。方法页同时展示 Pearson 线性相关、Spearman 秩相关、Fisher 95% 置信区间、近似双侧 p 值，以及 20 日、60 日和 252 日实际样本；统计不显著的短窗口结果仅作为方向参考。

## 数据口径

### ETF一级市场资金流

`估算净申赎 = 相邻披露日流通份额变化 × 当日 NAV`

流通份额和 NAV 来自 State Street、iShares、Global X 等基金发行商公开页面。该指标用于估算 ETF 创建与赎回，不代表二级市场主动买卖，也不等于全球全基金数据库。

### 其他资金流

- ICI：美国长期共同基金周度估算，不含 ETF。
- 美国财政部 TIC：外国投资者对美国长期证券的月度净买卖。
- 免费公开数据无法完整复制 EPFR、Wind 或 Choice 的全球基金、机构类型和日频行业资金流。

### 大宗商品

- 国际商品：Yahoo Finance 公开期货日线。
- 中国黑色系：新浪财经连续期货日线，覆盖螺纹钢、热卷和铁矿石。
- 管理基金仓位：CFTC Disaggregated Commitments of Traders 周报。
- 能源库存：EIA 官方数据。

连续期货和公开聚合行情适合趋势研究，不等同于具体可交易合约的实时成交报价。

- EIA：能源库存和供需数据。

- 新闻中文摘要：使用本地资产配置规则生成，不需要 Gemini API Key。

## 数据纪律

- 页面保留来源链接、数据日期、更新频率和来源状态。
- 每页均提供可展开的“数据来源审计”，区分主源、验证源、回退源，以及最新报价和历史计算序列。
- 历史行情按共同交易日对齐，并对最近 60 个共同观测同时比较复权价格偏差与日收益偏差；日收益均值偏差超过 5bp 或最大偏差超过 25bp 时不通过交叉核验。
- 数据质量摘要显示历史行情覆盖率、通过多日交叉核验的序列数、缓存/陈旧序列数，以及ETF资金流的已覆盖与可计算数量。
- ETF净申赎只在至少存在两个不同披露日的流通份额和NAV时计算；首日快照显示“建立跨日基线”，抓取失败显示“缓存沿用”，不会把空值当作零流量。
- `online` 表示本轮抓取成功，`cached` 表示本轮失败并沿用上一版，`fallback` 表示没有可用历史缓存。
- 页面不会用正弦曲线等模拟行情填补真实历史；真实历史不足时直接显示数据不可用或降低数据质量。
- Yahoo Finance属于非官方公开接口，不能作为生产级唯一主源；当前历史模型使用仍存续的代表性ETF，也不能消除退市样本带来的生存者偏差。该偏差通常会使历史收益和命中率偏高，并可能低估风险与相关性失效概率。
- 复权收盘价用于纳入分红与拆分，但不同提供方的复权时点、时区和收盘口径可能不同；页面通过同日收益交叉核验降低风险，不能替代点时数据库。
- Twelve Data 的ETF成分、行业、国别和资产配置接口属于 Ultra/Enterprise 等高阶套餐，当前免费方案不调用，也不会将缺失暴露数据标记为已覆盖。
- 资产打分、普林格周期阶段、产业链强度和资金价格状态均为研究模型输出，不构成投资建议或收益保证。
